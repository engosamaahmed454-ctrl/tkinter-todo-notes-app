# ✅ To-Do / Notes App

A simple desktop to-do list built with Python's `tkinter` library. Tasks are saved locally to `tasks.json`, so your list is still there the next time you open the app.

## Features

- Add tasks with the input box or by pressing Enter
- Check tasks off as done (shown with strikethrough)
- Delete tasks (with a confirmation prompt)
- Tasks persist between runs via a local JSON file

## Run it

```bash
python todo_app.py
```

Requires Python 3 (tkinter ships with most standard Python installs).

## Why I built this

A practical personal project to practice Tkinter layouts, widget state, and simple file-based persistence with JSON.
